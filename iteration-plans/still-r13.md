# Still R13 — Polish, App Store & Launch

## Theme
Final polish, prepare for public launch on the Mac App Store.

---

## Features

### 1. Polish Pass
- Review all animations for smoothness (60fps target)
- Verify accessibility: VoiceOver labels, Dynamic Type support, reduced motion
- Color contrast compliance
- Keyboard navigation for all features
- Final typography kerning and spacing audit
- Empty states for all lists
- Error handling for offline/cloud scenarios

### 2. Onboarding
- 3-screen onboarding for new users:
  1. "Welcome to Still" — set a daily reminder time
  2. "Choose your focus" — pick 1-2 priority categories
  3. "Ready to begin" — launch into first session
- Skip option (don't force onboarding)

### 3. App Store Assets
- App icon (1024x1024 master)
- Screenshots: 5-6 key screens with device frames
- App preview video (30s loop of breathing orb + session)
- Full App Store description (SEO-optimized)
- Keywords list
- Privacy policy page
- Support URL

### 4. Launch Checklist
- [ ] All features from R10-R12 complete
- [ ] App Store account configured
- [ ] TestFlight beta with 5+ external testers
- [ ] Privacy policy live
- [ ] Support email configured
- [ ] Pricing: Free (with unlock) or $4.99/month subscription?
- [ ] Family Sharing enabled?
- [ ] Age rating: 4+
- [ ] Marketing copy reviewed
- [ ] 1-week pre-launch press outreach
- [ ] Twitter/social announcement plan

## Technical Approach
- **Accessibility Inspector** for full audit
- **Localization** preparation (even if English-only launch)
- **Crashlytics** or similar for crash reporting
- **Analytics** (opt-in) for understanding user behavior
